# Estantería Común — Tarea 2

## Información general

Universidad CENFOTEC
Curso: SOFT-12 — Programación Web Avanzada

## Descripción

Estantería Común es una solución web para un club
de lectura comunitario.

La tarea se divide en dos aplicaciones que permiten
comparar la manipulación manual del DOM con el
modelo de componentes y estado de React.

## Parte A — Buscador de libros

Tecnologías:
- HTML5
- JavaScript con módulos ES
- Bootstrap
- Sass
- Open Library Search API

Funcionalidades previstas:
- Búsqueda de libros por título o autor.
- Visualización de resultados y detalles.
- Lista de lecturas con tres estados.
- Formulario de propuesta de lectura.

## Parte B — Tablero de lecturas

Tecnologías:
- React
- Vite
- JavaScript
- CSS adaptable

Funcionalidades previstas:
- Lista de libros del club.
- Filtros por estado y miembro.
- Resumen de lecturas.
- Formulario controlado para agregar libros.

## Instalación y ejecución

Las instrucciones definitivas se incorporarán
progresivamente conforme se implementen
ambas aplicaciones.

## Del DOM manual a React

Se completará al finalizar las dos partes,
incluyendo referencias a los archivos del código.
